// Concepts essentiels

Les Bases que Tout le Monde Doit Connaître

🌐

Protocoles de Communication

Un protocole est un ensemble de règles permettant à deux machines de communiquer — comme une langue commune entre équipements réseau.

📦

Encapsulation des Données

Les données voyagent en paquets. Chaque couche OSI ajoute un en-tête pour guider le paquet jusqu'à sa destination finale.

🔀

Routage & Commutation

Les routeurs dirigent les paquets entre réseaux via adresses IP. Les switches connectent les machines d'un même réseau via adresses MAC.

🔒

Sécurité & Chiffrement

SSL/TLS chiffre les communications. Les VPN créent des tunnels sécurisés. Les firewalls filtrent le trafic indésirable.

Le Modèle OSI — Les 7 Couches

Comment les données sont encapsulées et transmises couche par couche.

7
Application
Interface utilisateur. Gère les communications entre applications et le réseau.
HTTPFTPDNS
6
Présentation
Traduit, chiffre et compresse les données pour la couche Application.
SSLTLSJPEG
5
Session
Établit, maintient et termine les sessions entre applications.
NetBIOSRPC
4
Transport
Transmission fiable de bout en bout, gestion des ports et du flux.
TCPUDP
3
Réseau
Adressage logique (IP) et routage des paquets entre réseaux.
IPICMPOSPF
2
Liaison
Trames entre nœuds adjacents, adresses MAC, détection d'erreurs.
EthernetARP
1
Physique
Bits bruts sur le support physique — câbles, ondes, fibres optiques.
RJ45Fibre
